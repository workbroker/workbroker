# Rico.Work

Ferramentas de apoio para o dia a dia da assessoria de investimentos, publicadas com GitHub Pages.

## Ferramentas

- **Calculadora de rolagem** (`rolagem.html`): compara manter um título até o vencimento com vender antes (com deságio) e reinvestir em outro ativo, já descontando o IR.
- **Rebalanceador de carteira** (`rebalanceador.html`): carteira atual × alocação-alvo por classe, com simulação de trocas, aportes e resgates.
- Relatório de performance (em breve)
- Mercado ao vivo (em breve)

## Privacidade

O site é estático: nada do que é digitado é enviado para servidor. Os dados ficam apenas no navegador de quem usa.
