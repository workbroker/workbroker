# Rico.Work

Ferramentas de apoio para o dia a dia da assessoria de investimentos, publicadas com GitHub Pages.

## Ferramentas

- **Carteira e rebalanceamento** (`carteira.html`): importa o PDF do XPerformance (lido no próprio navegador), compara a alocação com a carteira recomendada do perfil (over/under), e monta as ordens de venda e compra acompanhando o novo balanceamento.
- **Troca de ativos** (`rolagem.html`): compara manter um título até o vencimento com vender antes (com deságio) e reinvestir, já descontando o IR, com gráfico de cruzamento das curvas.
- Relatório mensal (em breve)
- Mercado ao vivo (em breve)

## Privacidade

O site é estático: nada do que é digitado ou importado é enviado para servidor. PDFs e carteiras ficam apenas no navegador de quem usa.

## Terceiros

- [PDF.js](https://mozilla.github.io/pdf.js/) (Apache 2.0) em `assets/vendor/pdfjs`.
