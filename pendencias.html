Pendências

Salvo neste navegador

Tudo é salvo automaticamente. Ative a cópia na nuvem (passo abaixo) para não perder nada se trocar de computador, limpar o navegador ou o site mudar.

☁️ Cópia na nuvem (recomendado)

As pendências ficam guardadas num repositório privado do seu GitHub (só você vê). Assim elas continuam lá mesmo se o site mudar, o navegador for limpo ou você abrir em outro computador ou no celular. Configure uma vez em cada aparelho.

  1. No GitHub, crie um repositório privado chamado workbroker-dados (marque "Add a README file").
  2. Abra github.com/settings/personal-access-tokens/new: dê um nome, em Repository access escolha "Only select repositories" → workbroker-dados; em Permissions → Contents escolha Read and write; gere e copie o token.
  3. Cole o token abaixo e toque em Conectar.

O token fica salvo só neste navegador. As pendências têm códigos de clientes, por isso elas nunca vão para o repositório público do site.

Uma cópia de segurança de vez em quando também é uma boa ideia.
